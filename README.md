# RetroShift

Race. Earn. Upgrade. Repeat. A 16-bit-inspired pseudo-3D arcade racer in
Godot 4 / GDScript. Design: [retroshift-design-v0.4.md](retroshift-design-v0.4.md).

## Run

`make help` lists the shortcuts (`make run`, `make race TRACK=s_curve`, `make debug`, `make test`, ...).
Or call Godot directly:

```sh
godot --path .                          # play: garage → event → results → garage
godot --path . -- --track=s_curve       # free race on a track (skips the garage, no rewards)
godot --path . -- --opponents=1         # free race with 0-5 AI (default 5)
godot --path . -- --autodrive --debug   # hands-off free race with debug overlay
```

Tracks: `harbor_mile`, `lighthouse_loop`, `cliffside_run` (championship, `resources/tracks/*.tres`),
plus dev tracks `basic`, `straight`, `s_curve`, `hillcrest`, `valley`, `crest_into_curve`.

Progress (credits, upgrades, unlocks, best results) is saved to `user://profile.json`
(macOS: `~/Library/Application Support/Godot/app_userdata/RetroShift/`).

| Action | Keyboard | Gamepad |
|---|---|---|
| Throttle / brake | ↑ / ↓ (W / S) | RT or A / LT or B |
| Steer | ← → (A D) | Left stick, D-pad |
| Nitro | Space | X or RB |
| Pause / restart | Esc or P / R | Start / Back |
| Continue (results, pause menu) | Enter | Y |
| Debug overlay / next track (free race) | F1 or Tab / F2 | |

## Mobile

Touch controls appear automatically on touchscreens: ← → steer, ↑ gas, ↓ brake, flame = nitro,
II = pause. The race pauses when the app goes to the background. To try touch on desktop with a
mouse, and to simulate a notch:

```sh
godot --path . -- --touch --safe-area=88,0,88,32   # left, top, right, bottom insets in px
```

Building for devices (`export_presets.cfg` has iOS and Android presets):

1. Install Godot 4.7.2 export templates (Editor → Manage Export Templates).
2. The bundle ID is `ai.weilabs.retroshift`; for iOS, set your Apple team ID in the preset.
3. iOS: Xcode with the device paired. Android: JDK 17 and the Android SDK set in Editor Settings.
4. `godot --headless --export-debug "iOS"` (or `"Android"`); builds go to `build/` (ignored).



All art and audio are original and generated by code in `tools/assets/` (stdlib Python):
`gen_font.py` (5×7 bitmap font), `gen_sprites.py` (cars, scenery, backgrounds, HUD; also
writes `scripts/rendering/sprite_atlas.gd`) and `gen_audio.py` (sound effects and chiptune
music). The engine sound is synthesized live (`scripts/audio/engine_synth.gd`).
Run `make assets` after editing a generator; commit the regenerated files.

## Test

```sh
tools/run_tests.sh   # GUT, headless; same command CI runs
```

## Layout

- `scripts/track/` – `TrackSegment`, `Track` (lookup, continuous heading/height), test tracks, minimap
- `scripts/simulation/` – 60 Hz `RaceSimulation` (collisions, ranking, results), vehicle model, snapshots
- `scripts/rendering/` – camera-relative `RoadProjector`, far-to-near `RoadRenderer`, HUD
- `scripts/core/` – `Game` autoload (scene flow), race scene, input, versioned `SaveService` + storage
- `scripts/progression/` – upgrade table, events, player profile, economy (`Progression`)
- `scripts/ui/` – garage
- `scripts/audio/` – engine synth, race sound director
- `resources/events/` – event definitions (`.tres`)
- `scripts/ai/` – opponent AI (v_max target speed, follow/pass lanes); also drives `--autodrive`
- `tests/` – GUT tests
